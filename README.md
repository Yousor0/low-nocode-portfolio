> A landing page for a modern authentic Chinese restaurant, complete with a fully functioning booking and reservation system.

**🔗 Links**
- [GitHub Repo](https://github.com/Yousor0/claude-code-resturant-week2)
- [Live Site ↗](https://week2-resturant.vercel.app/)

**🛠 Stack**

`React` `Vite` `Node.js` `Express` `Framer Motion` `Prisma` `PostgreSQL`

**⚙️ What I Built**
- Full restaurant landing page with smooth animations via Framer Motion
- A reservation system backed by a Node/Express API and a PostgreSQL database via Prisma ORM
- Deployed on Vercel with a connected backend

**🔁 What I'd Do Differently**

The design works, but opening the site feels a bit cold. I'd go back and do more research into the visual language of authentic Chinese restaurants — warmer color palettes, texture, and imagery that makes a customer feel welcomed before they even scroll.
