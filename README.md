## 🥡 Golden Dragon Restaurant Page

> A landing page for a modern authentic Chinese restaurant, complete with a fully functioning booking and reservation system.

**🔗 Links**
- [GitHub Repo](https://github.com/Yousor0/claude-code-resturant-week2)
- [Live Site ↗](https://week2-resturant.vercel.app/)

**📸 Preview**

![Golden Dragon Preview]()

**🛠 Stack**

`React` `Vite` `Node.js` `Express` `Framer Motion` `Prisma` `PostgreSQL`

**⚙️ What I Built**
- Full restaurant landing page with smooth animations via Framer Motion
- A reservation system backed by a Node/Express API and a PostgreSQL database via Prisma ORM
- Deployed on Vercel with a connected backend

**🔁 What I'd Do Differently**

The design works, but opening the site feels a bit cold. I'd go back and do more research into the visual language of authentic Chinese restaurants — warmer color palettes, texture, and imagery that makes a customer feel welcomed before they even scroll.

## 🖥️ Linux Terminal Pomodoro

> A Pomodoro productivity timer styled like a Linux terminal, with user authentication, a global leaderboard, and session tracking.

**🔗 Links**
- [GitHub Repo](https://github.com/Yousor0/midterm-pomodoro-ai-project)
- [Live Site ↗](https://midterm-pomodoro-ai-project-17h7.vercel.app)

**📸 Preview**

![Terminal Pomodoro Preview](https://github.com/Yousor0/midterm-pomodoro-ai-project/raw/main/previews/preview.gif)

**🛠 Stack**

`React` `Vite` `Node.js` `Supabase Auth` `PostgreSQL`

**⚙️ What I Built**
- A Pomodoro timer with a retro Linux terminal aesthetic
- Light and dark mode toggle
- User authentication with session tracking across logins
- A global leaderboard to compete on focus time

**🔁 What I'd Do Differently**

The UI needs more polish at smaller sizes and some elements lose visibility and contrast, especially in light mode. I'd also rethink the task list UX: better keyboard navigation, clearer state management, and making it feel as native to the terminal theme as the timer itself.
